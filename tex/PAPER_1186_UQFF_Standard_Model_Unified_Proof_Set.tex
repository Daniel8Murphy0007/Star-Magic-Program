\begin{abstract}
Using the eleven locked UQFF primitives we close seven Standard-Model
puzzles: three-generation count, quark/lepton mass ladder, CKM/PMNS
mixing geometry, proton lifetime, muon $g-2$, $W$-mass anomaly, and
$B$-physics flavor anomalies. The universal half-spinor tilt
$1/12=\Ftrz\Phires=\KMex-1$ governs all four EW-scale anomalies
simultaneously. No new fields.
\end{abstract}
